☁️ วิธีเซฟข้อมูลพอร์ตขึ้น GitHub แบบถาวร:

1. สร้าง Repository บน GitHub (เช่น my-portfolio) แล้วอัปโหลดไฟล์ index.html นี้ขึ้นไป

2. ไปที่ GitHub Settings → Developer settings → Personal access tokens → Tokens (classic) สร้าง Token ที่ติ๊กสิทธิ์ repo

3. นำข้อมูลมากรอกด้านล่าง เมื่อกด "เซฟขึ้น GitHub" เว็บจะบันทึกไฟล์ portfolio_data.json ลงใน Repo ของแม็กโดยตรง เปิดดูและแก้ไขได้จากทุกอุปกรณ์!
